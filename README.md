# FastAPI Playground

A collection of my **FastAPI experiments, practice code, and learning notes** while learning and working with FastAPI.

This repository is basically my workspace for learning FastAPI. I use it to write code, try things out, experiment with different features, and keep a record of what I learn along the way.

## Why Did I Make This Repository?

I wanted one place where I could keep all the code I write while learning FastAPI.

Rather than trying to make every piece of code into a proper project, this repository is meant to capture the smaller things I build while learning — from basic examples and API endpoints to experiments with different FastAPI features and concepts.

It also gives me a place to come back to later when I need to remember how something works or revisit something I learned earlier.

## What's Inside?

The repository contains my FastAPI learning work, including:

* Small experiments and examples
* API development practice
* Different FastAPI features and concepts
* Code written while following tutorials or learning new topics
* Experiments and things I build while figuring out how FastAPI works

The structure may change over time as I learn more and explore different parts of the framework.

## How I Use This Repository

This isn't meant to be a single polished application.

Think of it as a **personal FastAPI playground** — a place to write code, break things, test ideas, and keep everything I learn in one place.

As I learn more about FastAPI, this repository will naturally grow with it.
